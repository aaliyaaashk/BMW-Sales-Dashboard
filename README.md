Saw a BMW dashboard concept recently and I couldn’t resist creating my own version of it! 🚀🚗

I challenged myself to design a BMW Sales Dashboard that brings multiple insights together cleanly and interactively. The dashboard highlights revenue growth 📈, top-selling models 🚘, sales by country 🌍, sales channels 🛒, and yearly sales trends 📊, making it easy to explore the performance of different models at a glance.

For this project, my main focus was on the dashboard design 🎨, layout 🧩, and visual storytelling 📊, how information can be structured to make insights clear, engaging, and easy to understand. The data used here is only for demonstration purposes, as the goal was to experiment with the design and overall dashboard experience.
